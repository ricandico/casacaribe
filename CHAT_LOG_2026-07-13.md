## Resumen de trabajo realizado

### 1. Historial de movimientos de caja (admin)

**Funcionalidad implementada:** Sistema completo de historial de movimientos de caja para administradores.

**Componentes:**

#### Backend (`main.cjs`):
- **Handler `get-movimientos-por-apertura`**: Obtiene movimientos de una sesión específica por `apertura_id`
- **Handler `get-historial-movimientos`**: Obtiene todos los movimientos con filtros (desde, hasta, usuario_id, tipo)

#### Preload (`preload.cjs`):
- `getMovimientosPorApertura(data)` — para ver movimientos de un cierre específico
- `getHistorialMovimientos(data)` — para historial completo con filtros

#### Frontend (`index.html`):
- **Modal `modalHistorialMovimientos`**: Vista completa con filtros
  - Filtros: fecha (desde/hasta), tipo (todos/ingresos/egresos)
  - Resumen: totales de ingresos, egresos, neto
  - Lista detallada de movimientos con iconos, concepto, usuario, fecha, monto
- **Botón "💸 Movimientos"** en header (solo admin, clase `btn-admin`)
- **Expansión en historial de cierres**: botón "Ver detalle" en cada cierre para ver movimientos individuales

**Permisos:**
- Solo usuarios con rol `admin` pueden acceder
- Botón visible/oculto automáticamente según el rol

**Archivos modificados:**
- `main.cjs` — +2 handlers SQL
- `preload.cjs` — +2 funciones API
- `index.html` — +1 modal, botón header, lógica de expansión en historial de cierres
- `FUNCIONALIDAD.md` — documentación actualizada
